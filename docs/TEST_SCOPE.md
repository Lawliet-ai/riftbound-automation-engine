# 公开测试范围

原开发仓库有 1,400 个测试文件。独立快照保留 572 个文件，验收结果为 5,179 条通过、2 条 TODO；TODO 不计入通过数。

排除的 828 个测试文件依赖文件系统内省、官方原文、私人开发文档或未分发的审计脚本，包含依赖闭包关联项。排除这些测试没有改变业务逻辑，也没有修改测试断言或把失败项改成跳过。

部分审计脚本根据原卡文生成测试集合。完整卡文不分发后，这些审计不能沿用原判据，因此本快照保留可独立运行的行为测试，不声称承接原仓的全部回归覆盖。

完整排除路径见 [EXCLUDED_TESTS.txt](EXCLUDED_TESTS.txt)。原开发历史保留于作者的私有备份，未导入本仓库。

本轮验证使用本机已有依赖；没有在全新环境重装 npm 依赖，也没有验证完整真人对局或公网部署。
